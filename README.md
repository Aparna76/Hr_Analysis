# HR Analytics Dashboard

## Project Overview
This project analyzes employee data to identify workforce trends, employee attrition, and key HR metrics.

## Tools Used
- Python (Pandas, NumPy)
- SQL
- Power BI
- Excel

## Key Features
- Employee Count Analysis
- Attrition Rate Tracking
- Department-wise Analysis
- Gender Distribution
- Average Age and Salary Metrics

## Skills Demonstrated
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Development
- KPI Reporting
