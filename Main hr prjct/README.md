\# HR Analytics Dashboard



\## Project Overview

This project analyzes employee data to identify workforce trends, employee attrition, and key HR metrics. The dashboard was developed using Python, SQL, and Power BI to provide actionable business insights.



\## Tools \& Technologies

\- Python (Pandas, NumPy)

\- SQL

\- Power BI

\- Excel



\## Key Features

\- Employee Count Analysis

\- Attrition Rate Tracking

\- Department-wise Employee Distribution

\- Gender Distribution Analysis

\- Average Age and Salary Metrics

\- Interactive Dashboard Visualizations



\## Process

1\. Collected and prepared HR data.

2\. Cleaned and transformed data using Python.

3\. Performed data analysis using SQL.

4\. Built interactive visualizations in Power BI.

5\. Created KPI cards and business reports.
